# AERIVA Testing and Verification Skill
Prevent unverified features from reaching production.

## Layers
Use unit, repository/database, Compose/UI, integration, emulator, physical-device, and release-build testing as appropriate.

## Network matrix
Test Wi-Fi, mobile data, no validated internet, slow/intermittent connectivity, transitions, captive portals, backend outage, airplane mode, permission denial, and process restart where applicable.

## Data usage matrix
Test zero history, normal use, spikes, background-heavy use, warning thresholds, exhausted budgets, reset periods, and insufficient forecast history.

## UI states
Test loading, processing, success, failure, retry, empty, offline, permission, stale, disabled, and duplicate-tap prevention.

Report exact environment and commands. Emulator validation is not real-hardware validation.
