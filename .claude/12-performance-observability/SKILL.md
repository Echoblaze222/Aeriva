# AERIVA Performance and Observability Skill
Measure before optimizing where possible.

Track cold start, rendering, database query time, sync latency, network measurement overhead, battery, memory, and APK size.

Avoid expensive composition, blocking work, repeated requests, and loading entire histories into memory. Prefer pagination, cached state, Flow, lifecycle-aware collection, efficient queries, and incremental updates.

Use structured internal events for network transitions, sync failures, measurement failures, permission changes, and background failures. Do not collect unnecessary personal data.

Errors need stable internal categories, safe user messages, diagnostic context where safe, and recovery paths. Never expose stack traces to users.
