# AERIVA Premium Native UI/UX Skill
Create a restrained, premium native experience.

## Brand
Midnight Black #0A0A0A
Silver #C0C6D1
Ice Blue #5EC8FF

Ice blue is an accent, not the dominant surface.

## Principles
Native Android behavior, calm hierarchy, generous spacing, purposeful motion, accessibility, clear feedback, minimal decoration, accurate data visualization, and no generic dashboard templates.

## State completeness
Every meaningful action should consider idle, pressed, processing, success, failure, unavailable, offline, permission required, retry, and cancellation where applicable. Never leave the user wondering whether a tap worked.

## Data visualization
Show units, period, limitations where relevant, empty states, and errors. Never use decorative fake charts.

## Copy
Be concise and factual. Avoid "perfect signal", "unlimited speed", "guaranteed ping", or similar unsupported claims. No em dash or emojis.
