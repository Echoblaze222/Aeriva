# AERIVA Claude Code Skills Package

Copy the `.claude` directory into the root of the AERIVA repository.

```text
AERIVA/
├── .claude/
│   └── skills/
├── app/
├── core/
└── settings.gradle.kts
```

This package provides repository-local guidance for Android engineering, data usage management, connectivity intelligence, community intelligence, networking, UI/UX, security, offline sync, persistence, background work, testing, performance, release engineering, and dependency governance.

These are engineering instructions, not proof that a platform capability exists. Claude must verify current official Android behavior and must never invent functionality.
