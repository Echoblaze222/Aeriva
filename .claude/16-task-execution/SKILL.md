# AERIVA Task Execution Skill
Use this workflow for every implementation task.

## Before coding
Read applicable skills, inspect the tree, read relevant product/architecture docs, locate existing implementation and call sites, identify tests and platform limitations, then write a short plan.

## During coding
Make the smallest complete change. Reuse existing architecture. Add tests for behavior changes. Complete user-visible states. Avoid unrelated refactors.

## After coding
Run configured formatting, unit tests, relevant UI/integration tests, affected-module build, inspect Git diff, search for newly introduced TODOs/placeholders, and check for secrets.

### Changed
### Decisions
### Verification
### Not verified
### Risks
### Next

Never call a feature complete if essential verification remains outstanding.
