# AERIVA Network Optimization Skill
Implement legitimate optimization without promising impossible carrier-level control.

Possible directions include network quality monitoring, network selection guidance, data-saving policies, supported VPN routing, diagnostics, recovery guidance, and Android-permitted app/network policies.

## VPN
If VpnService is used, document tunnel lifecycle, routing, DNS, MTU, IPv4/IPv6, failures, battery, privacy, and user consent. A VPN is not automatically an optimizer.

Never inspect or alter traffic beyond the documented architecture and privacy model.

If optimization fails, preserve normal connectivity where possible and provide recovery.
